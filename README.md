ESP32 Temperature Fan Alarm

Project Overview

An embedded systems project that monitors temperature using an ESP32 and an NTC temperature sensor. When the temperature reaches a specified threshold, a relay activates the fan and a buzzer generates an alert.

Components

- ESP32 development board
- NTC temperature sensor
- Relay module
- Fan
- Buzzer

Working Principle

1. The ESP32 reads the temperature sensor.
2. The measured value is compared with the configured temperature threshold.
3. When the threshold is reached, the fan and buzzer are activated.
4. When the temperature falls below the threshold, they are switched off.

Applications

- Temperature monitoring
- Electronic equipment cooling
- Basic thermal protection systems
